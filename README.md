## Description

This repository contains the files and activities completed for Laboratory 1 of CPE106L-4 Software Design Laboratory.

The laboratory focuses on software development tools, coding standards, GitHub repository management, and Git version control.

---

## Repository Contents

- `README.md` - Contains information about the laboratory and repository.
- `Tools_and_Standards.md` - Contains software development tools and coding standards.
- `LICENSE` - License information for the repository.
- `.gitignore` - Specifies files that should not be tracked by Git.
- `main.py` - Sample Python program used for the laboratory activity.

---

## Learning Objectives

The laboratory demonstrates the following:

1. Identification of software development tools and standards.
2. Creation and management of a GitHub repository.
3. Use of Git version control commands.
4. Use of GitHub collaboration features.
5. Proper documentation and coding practices.
